# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

ESP-IDF firmware (C, LVGL 9.3) for an Audiobookshelf player on the Waveshare ESP32-S3-Touch-LCD-1.85C
(360×360 round display, 8 MB PSRAM, 16 MB flash; V1 PCM5101 and V2 ES8311 audio boards, detected at runtime).
README.md has the full user-facing and technical write-up (hardware pins, SD layout, portal, bring-up notes).

## Build / flash

Requires ESP-IDF **v5.5**. Managed components (LVGL, esp_lvgl_port, LCD/touch drivers, esp_audio_codec,
esp_jpeg; see `main/idf_component.yml`) are fetched into `managed_components/` on first build.

```sh
. $IDF_PATH/export.sh
idf.py set-target esp32s3          # first time only
idf.py build
idf.py -p <port> flash monitor
idf.py erase-flash                 # clears NVS settings (Wi-Fi, server, tokens)
```

There are no unit tests or linters; verification is on-device via the serial log. `sdkconfig` is generated
and gitignored — make persistent config changes in `sdkconfig.defaults`. Partition table is `partitions.csv`
(single 6 MB factory app, no OTA).

### Debug build flags

Add to `main/CMakeLists.txt` as `target_compile_definitions(${COMPONENT_LIB} PRIVATE ...)`:

- `PLAYER_STATUS_LOG` – pipeline stats every second
- `PLAYER_NO_SYNC` – don't send progress to the server
- `LAYOUT_AUDIT` – reports tappable controls overlapping the edge arcs (see `ui.c` refresh_timer)
- `UI_CAPTURE` – scripted UI tour streamed as base64 RGB565 over the console (`ui/ui_capture.c`);
  convert with `python3 tools/capture_to_media.py serial.log docs/media` (needs ffmpeg). Use with `PLAYER_NO_SYNC`.
- `PORTAL_TEST` – opens the setup screen after the library loads

### Fonts

`main/ui/fonts/ui_font_{14,16,20}.c` are generated by `tools/gen_fonts.sh` (needs Node and a prior build for
LVGL's font sources). Don't hand-edit them; extend the character ranges in the script instead.

## Architecture

Single component `main/`, with all subdirectories compiled via `SRC_DIRS` (new `.c` files in those dirs are
picked up automatically; a new directory must be added to `main/CMakeLists.txt`). `WHOLE_ARCHIVE` is required
so `ui/lv_mem_psram.c`'s LVGL allocator hooks are linked.

- `hardware/` board bring-up (display, touch, IO expander, audio codec probe), battery, power (dim/off/deep
  sleep, BOOT button), SD card.
- `network/` Wi-Fi, captive setup portal (`portal.c` + HTML in `portal_page.h`), Audiobookshelf REST client
  (`abs_api.c`: login/token refresh on 401, items, progress, play sessions).
- `app/` NVS settings (`config.c`), library catalog and SD cache (`catalog.c`), cover cache, downloads, player,
  `ts_audio.c` (MPEG-TS -> AAC/MP3 elementary stream with frame-accurate skipping, for the audio module).
- `module/` host side of the ATOM Lite audio module link (Bluetooth A2DP headphones), over UART0 on the board's
  UART header (GPIO43 TX, GPIO44 RX). C++ (`audio_module.cpp`) behind a C API (`audio_module.h`).
  `AudioLinkProtocol.h` is a verbatim copy of `protocol/AudioLinkProtocol.h` from
  github.com/bigonionbots/atom-lite-audio-module: change it there first, keep wire changes backwards compatible
  (append fields; accept payloads at least as long as known). `config.h` has no C++ guards, so C++ files include it
  inside `extern "C"`.
- `ui/` the shell (`ui.c`), pages, widgets, and shared state in `ui_priv.h`.

### Task/threading model

- **`app_main` (main.c)** initialises everything, then loops every 200 ms: loads the library (SD cache first,
  then network with 30 s retry) and services requests the UI posts (`ui_take_library_request`,
  `ui_take_refresh_request`). Blocking network loads (`catalog_load_*`) belong here, never in the LVGL task.
- **LVGL task** (esp_lvgl_port). Every `ui_*`/`lv_*` call from another task must hold `lvgl_port_lock()`;
  functions suffixed `_locked` (and `ui_show_notice`) take the lock themselves. The UI pulls state rather than
  being pushed: a 250 ms `refresh_timer` in `ui.c` polls `player_get_status()`, `download_generation()`, etc.
  and refreshes whichever page/overlay is visible.
- **Player** (`app/player.c`): public calls only enqueue commands. Internally a control task (commands,
  session, progress sync every 20 s), a fetch task (HLS `.ts` segments into a 512 KB PSRAM ring) and a decode
  task (TS demux → AAC/MP3 → I2S). Playback uses ABS `forceTranscode` HLS; segment N always starts at N×6 s,
  so the playlist is never fetched — seeking means fetching segment ⌊t/6⌋ and dropping t mod 6 s. Downloaded
  books (`app/download.c`) store those same segments in `dl/<id>/audio.ts` with an offset index.
- **Audio module output**: `pipeline_start()` latches `audio_module_enabled()` into `s_to_module`. Then the decode
  task runs `module_run()` instead of `decode_run()`: TS demux, skip whole frames, send undecoded AAC/MP3 with
  a fresh stream id. Position = stream start + the module's STATUS `playedMs`. Playing/buffering state also comes
  from STATUS. The control task's `module_sync()` pushes pause/volume and restarts the stream at the last
  position if the link session changes (module rebooted). Changing the output posts `CMD_OUTPUT`, which re-seeks
  to the current position on the new output.

### UI data model

`ui_set_books()` hands the UI an `abs_book_t` array (`g_books`); the UI derives index-list views into it
(`g_alpha`, `g_continue`, `g_recent`, `g_downloaded`, `g_authors`) declared in `ui_priv.h`. The caller frees the
old array only after the next `ui_set_books()`. Pages expose `*_build/*_set_books/*_refresh` hooks called by
`ui.c`. Overlays (book sheet, episodes, library picker, setup) sit above the pages; the status row is built last
to stay on top.

Layout constants and colours live in `ui_priv.h`. Touch rule: Now Playing's edge arcs claim touches from ~150 px
from centre and the Library A-Z ring from ~160 px, so keep tappable bounding boxes inside those radii.

## Hardware constraints that shape the code

- **Internal SRAM (~512 KB) is the bottleneck, not PSRAM.** LVGL objects and most task stacks live in PSRAM.
- **Tasks with PSRAM stacks can't touch flash** (NVS writes, etc.): route them through `flash_safe()` in
  `app/config.c`.
- **SDMMC DMA corrupts PSRAM buffers:** SD file I/O goes through the internal-RAM bounce buffer in
  `hardware/storage.c`; keep `CONFIG_FATFS_VFS_FSTAT_BLKSIZE` at 0.
- With the screen off the CPU drops to 80 MHz and LVGL is paused while audio continues; deep sleep happens only
  when idle with nothing playing/downloading and no USB host.
- The HTTP User-Agent (`USER_AGENT` in `abs_api.c`) must stay non-default; some reverse proxies reject defaults.
